# Claude Editorial Artifact — release checklist

## Purpose and content

- [ ] One explicit page job and identifiable audience.
- [ ] Visible thesis → system/evidence → decision sequence.
- [ ] Task-specific copy; no lorem ipsum or generic filler.
- [ ] Sample metrics labeled, or factual claims sourced.
- [ ] Provenance, time, confidence, and status shown when they change interpretation.

## Official visual system

- [ ] The only base hue tokens are Dark, Light, Light Gray, Mid Gray, Orange, Blue, and Green.
- [ ] No custom dark-green or replacement brand hue remains.
- [ ] Official Dark `#141413` is the deep structural field and primary ink.
- [ ] Official Light `#FAF9F5` dominates the reading surface and on-Dark text.
- [ ] Official Green `#788C5D` is a restrained accent, not a dark-background substitute.
- [ ] Official Orange `#D97757` appears only at purposeful emphasis points.
- [ ] Blue is used only for a real semantic role.
- [ ] Typography carries the identity more than effects.
- [ ] Not a centered hero + generic three-card layout.

## Typography and rhythm

- [ ] Licensed Anthropic fonts are used only when already available; no font file is copied or fetched.
- [ ] Display weight and family match the chosen Editorial or Product mode.
- [ ] Body copy ≥16px.
- [ ] Comfortable line measure and generous reading line-height.
- [ ] Metadata and utility type are consistent and subordinate.
- [ ] Chinese emphasis does not depend on synthetic italics.
- [ ] Section spacing is larger than intra-section spacing.

## Components

- [ ] Cards only represent real objects or interaction boundaries.
- [ ] Radius is mostly 0–10px.
- [ ] Shadows are absent or extremely restrained.
- [ ] Primary action is Dark with Light text unless the brief requires another official semantic token.
- [ ] Empty, error, and loading states explain what happens next.

## Responsive and accessibility

- [ ] Desktop asymmetry becomes a coherent mobile order.
- [ ] Essential content and actions remain visible on narrow screens.
- [ ] Wide tables or ledgers have a mobile strategy.
- [ ] Touch targets ≥44×44px.
- [ ] Keyboard focus is visible.
- [ ] Text contrast meets WCAG AA.
- [ ] Status is not encoded by color alone.
- [ ] `prefers-reduced-motion` is respected.
- [ ] Charts and diagrams have accessible labels or text summaries.

## Trust and implementation

- [ ] Existing repository stack and conventions are reused.
- [ ] No proprietary Anthropic font, logo, screenshot, illustration, or product asset is included.
- [ ] The implementation is described as independent and based on public style guidance.
- [ ] No unsupported claim of pixel-perfect fidelity is made.
- [ ] No unnecessary styling dependency is added.
- [ ] Type, lint, and build checks run when available.
- [ ] Every route is opened in a real browser when browser tooling is available.
