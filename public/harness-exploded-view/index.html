    别人怎么分包

    源码读于 2026-10-29

    Pi earendil-works/pi，v1.4.0

    按层拆成 11 个小包，全部在 @earendil-works 下。pi-ai 统一多厂商模型；pi-agent-core 是 agent 运行时，只依赖 pi-ai；pi-durable 是持久化的对话、任务与文档运行时，依赖 pi-ai、pi-codemode、pi-telemetry、chord；pi-env 是 pi-durable 的远程执行环境（SSH 部署的守护进程）；pi-mcp 是独立的 MCP 客户端；pi-codemode 是只能调用注入工具的沙箱 JS；pi-telemetry 是零依赖的遥测合同；pi-evals 做评测；pi-tui 是终端 UI；chord 负责插件、复制状态与 RPC；pi-coding-agent 是 CLI，把上面的包拼起来。Skills 和上下文压缩放在 pi-coding-agent 里，没有跨会话记忆。

    AI SDK 7 ai@7.0.156

    按合同拆小包。provider 接口包零依赖；ai 内核；约 45 个模型厂商包；harness 定义 HarnessV1，已有 claude-code、codex、cursor、fx、pi 等 11 个适配器；另有 workflow、sandbox-vercel、policy-opa、tool-bash、mcp、otel。没有记忆与 skills。

    Mastra

    一个大 @mastra/core（agent、loop、memory、skills、workspace、hooks、storage、evals 等 60 多个子模块）＋按类别分目录的适配器：stores 32 个、workspaces 20 个沙箱、observability 15 个、channels、server-adapters、deployers。memory 单独成包。

    fx vercel-labs

    Zig 单个二进制，src/core 内分 agent、session、compactor、permissions、hooks、skills、subagent、mcp、workspace；对 JS 只发一个 libfx 包，用子路径导出 node、wasm、durable-*、mcp、skills。没有跨会话记忆。

    借鉴：telemetry 和 MCP 做成零依赖的独立包（Pi）、接口带版本号（AI SDK）、适配器按类别分目录（Mastra）、对外一个包加子路径导出（fx）。
